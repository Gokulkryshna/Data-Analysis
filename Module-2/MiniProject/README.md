
# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Project Overview

Customer Shopping Behaviour Analysis is a data analytics project focused on understanding customer purchasing patterns, sales performance, customer preferences, and shopping behaviour.

The project involves data cleaning and preparation using Microsoft Excel, followed by interactive data visualization and analysis using Microsoft Power BI.

The main objective is to transform raw customer shopping data into meaningful insights that can help businesses understand their customers and make better business decisions.

## 🎯 Project Objectives

- Analyze customer purchasing behaviour.
- Understand sales and revenue performance across product categories.
- Identify customer demographics and purchasing patterns.
- Analyze subscription status and customer preferences.
- Evaluate discount usage and shipping preferences.
- Generate business insights and recommendations based on the analysis.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning and preprocessing.
- **Microsoft Power BI** – Data visualization and interactive dashboard development.
- **GitHub** – Project documentation and portfolio management.

## 📂 Dataset Information

The project uses a Customer Shopping Behaviour dataset containing **3,900 records and 19 columns** after data cleaning.

Important dataset attributes include:

- Customer ID
- Age
- Gender
- Age Group
- Category
- Item Purchased
- Purchase Amount
- Season
- Payment Method
- Discount Applied
- Subscription Status
- Review Rating
- Shipping Type
- Previous Purchases
- Purchase Frequency

## 🧹 Data Cleaning & Preparation

Data cleaning and preprocessing were performed using Microsoft Excel.

The following steps were completed:

1. Imported and examined the raw dataset.
2. Checked for duplicate records.
3. Identified and handled missing values in the Review Rating column.
4. Standardized column names for consistency.
5. Removed the redundant Promo Code Used column because it contained the same values as Discount Applied.
6. Created an Age Group column to categorize customers.
7. Created a Purchase Frequency Days column for additional behavioural analysis.
8. Saved the cleaned dataset for Power BI visualization.

Based on the analysis, the project explores the following business strategies:
